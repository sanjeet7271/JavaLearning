### Pass by value and pass by reference
- **Pass by reference**: Suppose a professor sends the original copy of the note to the student, and the student modifies it or deletes it. In that case, the professor again will not get their original copy. That's the pass by reference. means modifying the original address
- **Pass by value**:  Suppose a professor sends a copy of the original note to the student, and the student modifies it or deletes it. that wont impact original note. In that case, the professor can send a copy of the original note to another student. That process won't impact its original note. That's the pass by value. means modifying only the copy of the original address.
